# F5 — Installable app and launch at login

Created: 2026-10-18 10:55 -05:00 · Edited: 2026-10-18 11:15 -05:00

**Status:** planned, awaiting the gate · **Milestone:** MVP · **Owner:** agent · **Delivers:** FR7

Runs before F4 in today's order (D9): without a bundle the app cannot post notifications or register for login, and it cannot run overnight for F3's evidence. Learning level 5% proposed (`O2`); every task is `owner: agent`.

## Design

- `scripts/build-app.sh`: `swift build -c release`, wrap into `build/DockWatch.app` with `Resources/Info.plist` (`LSUIElement` true, bundle id `com.martingleason.dockwatch`), ad-hoc `codesign` with hardened runtime, `--install` copies to `~/Applications`. Mirrors HueBar's script, minus the Icon Composer step until an icon exists.
- `LaunchAtLogin` (DockWatch): `SMAppService.mainApp.register()` / `unregister()`, status read from `SMAppService.mainApp.status`. A menu toggle.

## Tasks

T1 then T2.

### F5-T1 — Bundle script, Info.plist, entitlements

Owner: agent · Delivers an app the owner can install · Checkpoint: `scripts/build-app.sh --install` then `open ~/Applications/DockWatch.app` shows the icon; `codesign -dv` shows hardened runtime.

### F5-T2 — Launch-at-login toggle

Owner: agent · Delivers FR7 · Checkpoint: toggle on, log out and in, the icon is present; System Settings → General → Login Items lists DockWatch.
