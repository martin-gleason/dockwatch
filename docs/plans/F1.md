# F1 — Menu bar presence and dock detection

Created: 2026-10-18 10:55 -05:00 · Edited: 2026-10-18 11:15 -05:00

**Status:** in progress (gate crossed 2026-10-18) · **Milestone:** MVP · **Owner:** agent · **Delivers:** FR1, FR2

Learning level 5% proposed (`O2`); every task is `owner: agent`.

## What the user gets

An icon in the menu bar that tells the truth about the dock: docked, or not. Plugging the dock in or pulling it changes the icon within a second, with no timer anywhere.

## Design

- `DockIdentity` (DockCore, pure): a vendor/product pair with a `matches(vendor:product:)` function. Default `0x1532:0x122E`, the USB device macOS names "Thunderbolt 4 Dock". The Chroma lighting controller on the same dock enumerates as `0x24F0:0x0F21` and must **not** match (M4); matching on vendor alone would also match any Razer mouse.
- `USBMonitor` (DockCore, IOKit): `IOServiceAddMatchingNotification` for `IOUSBHostDevice` on `kIOFirstMatchNotification` and `kIOTerminatedNotification`, reading `idVendor`, `idProduct`, `USB Product Name`, `locationID` from the registry entry. Delivers `USBEvent(.attached | .detached, descriptor)` on the main run loop. Primes itself by iterating the initial match set so launch-while-docked is seen (FR2).
- `DockState` (DockCore, pure): folds USB events into `.docked | .undocked`.
- `StatusItemController` (DockWatch, AppKit): an `NSStatusItem` with three SF Symbol variants for FR1's three states. The "held" variant is wired in F3; in F1 it renders the two it can know.

## Tasks

Strictly sequential; runs serially.

### F1-T1 — Package skeleton and an empty status item

Owner: agent · Delivers nothing user-visible (foundational) · `Package.swift` with three targets, `Resources/Info.plist` with `LSUIElement`. Checkpoint: `swift run DockWatch` shows an icon; `swift test` green.

### F1-T2 — DockIdentity and DockState

Owner: agent · Delivers FR2 logic · Checkpoint: tests show the default identity matches the dock, rejects the Chroma controller and a Razer mouse.

### F1-T3 — USBMonitor

Owner: agent · Delivers FR2 · First-match and terminated notifications, primed at launch. Checkpoint: pull the dock's cable and a `.detached` event arrives with product name "Thunderbolt 4 Dock".

### F1-T4 — Status item renders dock state

Owner: agent · Delivers FR1 (two of three states) · Checkpoint: the icon changes within 1 s of pulling or replugging the dock.
