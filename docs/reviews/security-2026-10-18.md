# Security review — black-hat pass before the overnight experiment

Created: 2026-10-18 18:58 -05:00 · Edited: 2026-10-18 20:10 -05:00

**Reviewed:** `main` at `9a1987d` (after PRs #1–#10), the installed bundle at `~/Applications/DockWatch.app` (built 16:50 from F5), the public repository and its settings. Three reviewers in fresh contexts, each in its own clean clone, each briefed as an attacker on one surface: hostile inputs (USB strings, DiskArbitration descriptions, the log file), the local attacker and runtime (tampering, persistence, sandbox, memory safety), and the supply chain (build script, CI, hooks, published data). The author verified every finding carried below against the source, the bundle or the repository settings before recording it. Ordered by what the attacker gets.

**Verdict.** No memory-safety defect, no privilege escalation, no network, no subprocess, no secrets logged. The app runs sandboxed with one entitlement, hardened runtime on, no dyld or library-validation exceptions, and the only privileged act it performs (an unforced unmount) re-validates the target at click time. Two things are real and both sit outside the Swift: the bundle's signature does not pin an identity, and running an untrusted branch of this repository runs that branch's code on the owner's machine. The rest is hardening the plan C3 does, and settings only the owner can change.

## What the reviewers ran

Hostile inputs: throwaway XCTests through `EventLine`, `EventStore`, `EventQuery`, `LossCoalescer`, `DockMembership`, `DockTracker`, `EjectMenuModel` and `HoldPolicy` with newline, CR, NUL, RTL-override, zero-width, 100 000-deep JSON, duplicate keys, 700 KB unterminated lines, 3.4 MB files, a directory and a symlink in place of the log. Local attacker: `codesign -dvvv --entitlements -`, `codesign -d -r-`, `codesign --verify --deep --strict` before and after patching and re-signing a scratch copy of the bundle, `sfltool dumpbtm`, `launchctl print`, `pmset -g assertions`, ASan over all 55 tests (xctest bundle run directly with the sanitizer runtime inserted; the SwiftPM host cannot load interceptors), a read of every C-API call site, cross-user read of the container as a second local user. Supply chain: `scripts/build-app.sh` line by line and run without `--install`, a symlink smuggled into the `.icon` bundle, `Package.swift`, `Info.plist`, the entitlements, `gh api` on branch protection, rulesets, Actions permissions, secrets, caches, deploy keys, collaborators, the pre-commit secret regex against a staged file of fakes, and `git log -p --all` for personal data.

## Attacked and held

- Newline and CR injection through a device name: `JSONEncoder` escapes them; `tail` splits one line. Deep JSON (100 000 levels), duplicate keys, torn writes, unknown kinds: `decode` returns nil or the first value, nothing crashes. The log as a directory: `append` reports *Is a directory* through the menu's problem line.
- Memory safety: ASan clean across all 55 tests; `proc_listpidspath` buffer sized in bytes with slack; `Unmanaged.passUnretained` in every monitor paired with `stop()` in `deinit` on an object AppKit owns for the process lifetime; all IOKit, DiskArbitration and IOPS callbacks on the main run loop in `.commonModes`; no AppKit off the main thread.
- The eject path: `isRelevant` excludes internal volumes, virtual interfaces and `/.timemachine/`; `dockVolumes()` requires the dock controller byte; `eject(bsdName:)` re-resolves the volume at click time; unmount is never forced; the boot volume cannot appear. Verified by trace, not run, because the dock is unplugged.
- Dylib injection and debugger attach against the installed binary: hardened runtime, no `allow-dyld-environment-variables`, no `disable-library-validation`, no `get-task-allow`.
- `keepDockAwake` flipped under the app: read once at launch, and the hold needs the dock present. The IOPM assertion dies with the process; `pmset -g assertions` shows none orphaned.
- Cross-user read of the log: `~/Library` is 0700; a second local user cannot traverse.
- `scripts/build-app.sh`: every variable quoted, every `rm -rf` a literal under `build/`, a symlinked `Ring.png` makes `actool` fail the build, `Info.plist` carries no `LSEnvironment` or `DYLD_*`, no tracked symlinks, no plugins, no `unsafeFlags`, no dependencies, nothing fetches from the network at build or test time.
- GitHub: no secrets, variables, deploy keys, environments or caches; the owner is the only collaborator; all ten PRs came from the owner's branches; the default workflow token is read-only.
